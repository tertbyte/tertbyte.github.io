# Mohammed Shazin — Portfolio

A responsive, single-page personal portfolio built with HTML, CSS and vanilla JavaScript.

## Sections
- Introduction and social links
- Selected projects: Data Detective, BloodOn, NovaForge, Tert Studio
- Technical, design, and workflow skills
- Education, Keltron training, and freelance background
- Contact and collaboration links

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Deploy
The `shazin-portfolio` folder is deployed as a standalone Vercel project from this repository's `main` branch.

Project descriptions are presented as concepts or ongoing explorations where appropriate; add verified live project URLs as they become available.
