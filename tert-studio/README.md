# Tert Studio

Premium, responsive one-page studio website built with HTML, CSS and vanilla JavaScript.

## Sections
- Animated hero and brand artwork
- Selected concept projects
- Services grid
- Studio introduction
- Four-step process
- Contact form that prepares an email draft
- Responsive mobile navigation and reduced-motion support

## Deploy
This directory is configured as the root directory for the Vercel project **tert-studio**. Pushes to `main` trigger a deployment.

The project cards are concept previews. The contact form uses `mailto:` and does not send submissions to a server.
